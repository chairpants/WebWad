Rise of the Triad

in a browser, from your own game files

Library

Open a pack to see its levels; anything opened once is kept in this browser. The user levels come from archive.org's ROTT user levels collection and are played over . Most were made for the registered game, whose walls and enemies the shareware art lacks; add your own DARKWAR.WAD below and they are played over that instead. A pack with its own WAD has it laid over, as ROTT's -file does.

add your own

A game's .WAD and its levels (.RTL, .RTC), a user level on its own, or a .zip of any of those. Nothing is uploaded anywhere; they stay in this browser.

Name a WAD or level file and the other comes with it if it sits beside it.

The host has to allow cross-origin reads, which is a different thing from the file being public. Archive.org allows it for a file inside a zip (…/ROTT.zip/HUNTBGIN.WAD) but not for the zip itself, so name the file.
