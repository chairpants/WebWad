A .zip brings both files in one go, and less of them: 3.7 MB against 6.5 MB loose.

The host has to allow cross-origin reads. Archive.org does, both for a zip and for a file inside one (…/ROTT.zip/HUNTBGIN.WAD); a host that does not will fail here and not in your browser's address bar.
